· 새 노선 → 정류장을 순서대로 클릭 → Enter(완료)
  첫 정류장을 다시 클릭하면 순환 노선
  Backspace: 마지막 정류장 취소 / Esc: 취소
· ✏️ 노선 수정: 새 정류장 클릭 → 추가, 노선 정류장 클릭 → 빼기, Enter 적용
· 속이 빈 원 = 미보유 정류장 (클릭해서 구입 후 노선에 사용)
· 버스 구입 → 차고지 → 노선 선택 → 배차
· 🚐 마을 20~30명 · 🚌 시내 35~45명 · 🚍 고속 50~60명 (빠름)
· 업그레이드·매각은 차고지에서만 (Lv1→3)
· 운영비는 운행 중인 버스만 냅니다
· 도로 굵기 = 차선 수 (주황 고속도로 · 밝을수록 큰 길)
· 정류장 크기 = 실제 하루 평균 승차 인원
· 숫자 배지 = 기다리는 승객
· 출근 7~9시 · 퇴근 17~19시 반에 승객이 2~3배. 만차면 못 탐
· 승객은 1회까지 환승합니다 (환승 무료)
· 배차가 잦을수록 승객이 늘고, 오래 기다리면 떠납니다
· 만족도가 높으면 평판이 올라 다음 날 수요가 늘어납니다
· 승객 목적지는 노선이 닿는 곳으로만 정해집니다
· 적자여도 만족도 60% 이상이면 준공영제 보조금(적자의 50%)
